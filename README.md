Cada conjunção funciona como uma ponte que liga uma ideia à outra, ajudando o texto a fazer sentido.
Para atravessar de um lado do lago ao outro, você deverá escolher a ponte correta, ou seja, a conjunção
que melhor completa a frase. Leia cada frase com atenção, observe a relação entre as ideias e selecione
a conjunção adequada.
